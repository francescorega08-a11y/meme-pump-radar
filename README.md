# meme-pump-radar
Solana Meme Coin Radar with AI-assisted market analysis.
Obiettivo
Monitorare meme coin sulla blockchain Solana.
Considerare solo token con liquidità minima di $25,000.
Rilevare possibili segnali anticipati su un orizzonte di 30 minuti–2 ore.
Analizzare prezzi, volumi e menzioni social accessibili.
Inviare alert automatici su Telegram.
Fornire una dashboard web accessibile da iPad.
Sicurezza
Nessun acquisto automatico.
Nessuna chiave API o password nel codice.
Iniziare con servizi gratuiti.
